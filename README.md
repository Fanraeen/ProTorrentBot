# [@ProTorrentBot](https://t.me/ProTorrentBot)

Telegram-бот для поиска и скачивания `.torrent`-файлов: [@ProTorrentBot](https://t.me/ProTorrentBot).

## Возможности

- Поиск торрентов по запросу прямо в чате Telegram
- Просмотр подробной информации о выбранной раздаче
- Скачивание `.torrent`-файла по кнопке под сообщением

## Как пользоваться

1. Отправьте боту команду `/start`.
2. Введите поисковый запрос, и бот покажет список найденных раздач.
3. Нажмите на команду `/torrent...` рядом с нужным результатом, чтобы открыть подробности.
4. В карточке раздачи нажмите на инлайн-кнопку, и бот пришлёт `.torrent`-файл.
